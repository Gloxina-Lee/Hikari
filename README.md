# Hikari Theme

> 一个 WordPress 主题，对 Sakurairo 进行二次修改。

## 下载及使用相关：

- 前往 [Github Release](https://github.com/Gloxina-Lee/Sakurairo) 下载。

## 主题说明：

### 开源相关：

- 本主题基于 [Sakurairo](https://github.com/mirai-mamori/Sakurairo) 主题进行二次修改，继承 [GPL-2.0](https://github.com/mirai-mamori/Sakurairo/blob/master/LICENSE) 开源协议进行开源。

- 本主题使用了部分来自互联网的特效，该部分继承 Sakurairo 原有特效。由于版权及开源协议不明，无法具体说明相关信息。如果本主题中的内容侵犯了您的权益，烦请您通过电子邮件 [im@gloxina.com](mailto://im@gloxina.com) 来与我取得联系。

### 引用相关：

- 本主题社交网络图标中，流畅设计图标引用于由 Paradox 设计的 Fluent 图标包

- 本主题社交网络图标中，沐氢图标引用于由缄默设计的沐氢图标包

### 依赖相关：

- 本主题使用 Codestar [Codestar Framework](https://github.com/Codestar/codestar-framework) 作为设置框架


- 本主题使用 Themeum [Kirki](https://github.com/themeum/kirki) 以提供可视化编辑器相关功能
